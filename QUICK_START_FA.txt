DeutschRitter — راهنمای بسته کامل
================================
۱. ZIP را کامل استخراج کنید؛ index.html را داخل خود ZIP اجرا نکنید.
۲. پوشه js و فایل‌های دیگر را جابه‌جا یا حذف نکنید.
۳. برای اجرای ساده، index.html را باز کنید؛ در ویندوز Deutsch-lernen.bat همین کار را می‌کند.
۴. برای استفاده از Service Worker روی همان دستگاه:
   python -m http.server 8000 --bind 127.0.0.1
   سپس در مرورگر باز کنید: http://localhost:8000
   Python فقط برای این روش لازم است؛ برای اجرای مستقیم HTML ضروری نیست.
۵. اجرای محلی یعنی انتشار عمومی انجام نمی‌شود.
۶. از بخش مدیریت پیشرفت مرتباً خروجی JSON بگیرید. این ZIP شامل پیشرفت شخصی شما نیست.
۷. در مرورگر دارای Web Locks فقط یک تب اجازه ذخیره دارد. تب دیگر می‌تواند خروجی بگیرد؛ برای انتقال کنترل، تب فعال را ببندید و راهنمای بازخوانی را دنبال کنید. در مرورگر فاقد این API هم‌زمان در چند تب بازی نکنید.

محتویات مهم:
- index.html و js/: برنامه و داده‌ها
- PREVIOUS_VERSION_AUDIT.md: ممیزی نسخه اولیه، اصلاحات و ایرادهای باز
- PROJECT_REPORT.md: گزارش تقویت آموزشی و بازتحلیل
- README.txt: راهنمای کامل و محدودیت‌ها
- TEACHING_GUIDE.md: روش تمرین و بازبینی توسط مدرس
- RELEASE_CHECKLIST.md: شروط تأیید و انتشار
- tests/ و scripts/: تست و ابزار ممیزی/بسته‌بندی
- SHA256SUMS.txt: checksum فایل‌های بسته
- BUILD_INFO.json: مشخصات بسته و مبنای مخزن

توسعه و تست (برای استفاده عادی لازم نیست):
Node.js 22.17 به بالا در شاخه 22، یا 24 به بالا نصب کنید و در پوشه استخراج‌شده اجرا کنید:
  npm ci
  npm test
npm ci برای دریافت وابستگی تست به اینترنت نیاز دارد.

محدودیت‌ها:
این بسته یک ابزار تمرین غیررسمی A1/A2 است، نه گواهی یا دوره تأییدشده گوته.
MP3های ادعاشده در نسخه اولیه در مخزن موجود نیستند و در این ZIP نیز وجود ندارند.
صدا از TTS مرورگر تأمین می‌شود و ممکن است به اینترنت یا نصب صدای آلمانی سیستم نیاز داشته باشد.
B1، رابط چندزبانه و ممتحن معتبر نوشتن/گفتن در این نسخه وجود ندارند.
تأیید مستقل همه محتوای آلمانی و تست واقعی گوشی/نصب انجام نشده است.
