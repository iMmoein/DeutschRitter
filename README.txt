DeutschRitter — شوالیه آلمانی | آموزش و بازی جامع گوته A1 و A2 (نسخه P8 — نهایی)
========================================================================
چطور اجرا کنم؟
  روی index.html دابل‌کلیک کن — توی مرورگر باز می‌شه.
  برای صدای واقعی MP3، پوشه audio/ و فایل sw.js باید کنار index.html بمونن (داخل ZIP هست).
  اگه فایل MP3 پیدا نشه، بازی خودکار به صدای سیستم (TTS) برمی‌گرده.

فقط آلمانی (German-only) — پیش‌فرض روشن:
  ترجمه فارسی لغات، مثال‌ها، مکالمه و متن خواندن پنهان است تا مغزت مستقیم آلمانی فکر کند.
  برای دیدن ترجمه، از نقشه جهان دکمه «حالت فقط‌آلمانی» را خاموش کن.

چی داره؟
  - ۸ پرده داستانی (A1: پرده ۱ تا ۴ | A2: پرده ۵ تا ۸) + نبرد با غول در هر پرده
  - ۱۰۱۴ کلمه با آرتیکل، جمع، IPA کامل و مثال (پوشش کامل A1 + A2 گوته)
  - ۲۶ موضوع گرامر (هر پرده ۳-۴ موضوع) + تمرین فوری + جدول صرف ۲۸ فعل + ضمایر کامل با جدول و مثال
  - آموزش اول، بعد آزمون — هر پرده: آواشناسی، لغات، گرامر، مکالمه، مهارت‌ها، خواندن، باس
  - بانک سوال تطبیقی باس: هر بار ترکیب جدیدی از سوال‌های ثابت + سوال‌های تصادفی از لغات پرده
  - شبیه‌ساز آزمون گوته زمان‌دار (۳۰ دقیقه، ۴ مهارت، نمره /۱۰۰، قبولی ۶۰، نمره جزئی شنیداری)
  - مهارت‌های گوته: هجی، اعداد/ساعت/تاریخ، دیکتاتور، شنیداری (Hören)، نوشتن با تصحیح خودکار، گفتن با ضبط صدا + تشخیص گفتار هوش مصنوعی
  - ۸۳۹ فایل صدای واقعی MP3 (همه لغات + دیکتاتور + مکالمه‌ها) + TTS برای بقیه
  - ۲۲ متن خواندن درجه‌بندی‌شده (A1 تا A2، ۹۰ تا ۱۱۸ کلمه) با ۵ سوال درک مطلب
  - قصر حافظه FSRS (پایداری‌محور) برای لغات + گرامر (جای خالی) + شنیداری، سقف ۲۰ کارت جدید در روز
  - داشبورد پیشرفت: نرخ یادسپاری، کارت‌های آماده مرور، کارت‌های مسلط
  - کلاس قهرمان با بونوس واقعی: Krieger (+۵۰٪ طلا) | Magier (+۲۰٪ XP) | Schütze (+۲۵٪ آسیب)
  - فروشگاه: جان اضافه، راهنما، بسته XP با طلا
  - برنامه ۹۰ روزه مطالعه با تسک روزانه مشخص
  - هدف روزانه XP + streak واقعی + خروجی/ورودی پیشرفت (JSON)
  - آزمون تعیین سطح ۴۰ سوالی (۴ شنیداری + ۳۶ نوشتاری) + تحلیل خطای باس + گواهی پایان دوره
  - ۸ عکس واقعی برای پرده‌ها + PWA با Service Worker (نصب روی موبایل، آفلاین کامل)

نکته: گواهی داخل بازی و نمره شبیه‌ساز، گواهی بازی است و مدرک رسمی گوته نیست.
