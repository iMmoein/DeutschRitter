DeutschRitter — German practice RPG (A1/A2 content)
=================================================
اجرای مستقیم: index.html را در مرورگر باز کنید.
اجرای محلی با پشتیبانی Service Worker:
  python -m http.server 8000 --bind 127.0.0.1
سپس http://localhost:8000 را روی همان دستگاه باز کنید.
این کار انتشار عمومی یا نیاز به سرویس ابری نیست.
برای دسترسی از دستگاه دیگر باید تنظیم شبکه و HTTPS جداگانه انجام شود.

وضعیت واقعی نسخه:
- ۸ پرده A1/A2؛ هنوز B1 و رابط چندزبانه پیاده نشده است.
- ۱۰۱۴ ورودی واژگان، ۷۸۹ عبارت آلمانی یکتا؛ وجود IPA به معنی تأیید صحت آن نیست.
- ۸ متن پرده‌ای + ۲۲ متن کتابخانه (جمعاً ۳۰)؛ تمرین‌های قبلی به‌علاوه ۵۲ تمرین موضوعی تازه و ۲۰ کارت گرامر SRS.
- ۴۰ سؤال تعیین سطح (۴ شنیداری + ۳۶ متنی).
- زمان‌بندی مرور سفارشی پایداری‌محور است، نه FSRS استاندارد.
- فایل‌های MP3 در این مخزن موجود نیستند؛ صدا از TTS مرورگر تأمین می‌شود.
  زبان آلمانی سیستم و مرورگر باید در دسترس باشد؛ صدای آفلاین تضمین نمی‌شود.
  فقط پس از نصب کامل فایل‌های audio/ می‌توان پیش از اجرا
  window.DEUTSCHRITTER_AUDIO_INSTALLED = true را تنظیم کرد.
- پوسته برنامه پس از بارگذاری موفق در localhost/HTTPS کش می‌شود.
  file:// از Service Worker پشتیبانی نمی‌کند. نصب PWA به مرورگر وابسته است.
- حالت فقط‌آلمانی بعضی ترجمه‌ها را مخفی می‌کند؛ رابط هنوز فارسی است.
- نوشتن شمارش ساختاری و چند هشدار محدود دارد، بدون نمرهٔ مهارت یا ادعای تصحیح جامع گرامر.
- گفتن تطابق متن را نشان می‌دهد، بدون نمرهٔ خودکار آزمون.
- تمرین زمان‌دار فقط خواندن/شنیدن را با مجموع ۵۰ امتیاز می‌سنجد؛ نوشتن و گفتن نیازمند بازبینی انسانی‌اند.
  نتیجه معادل آزمون یا گواهی رسمی گوته نیست و پوشش کامل گوته تأیید نشده است.
- پیشرفت روی دستگاه ذخیره می‌شود؛ مرتباً از داخل بازی خروجی JSON بگیرید.

تست‌های رگرسیون (Node.js، بدون نصب وابستگی):
  node tests/regression.cjs

- شنیداری اطلاعاتی با سؤال و پاسخ آلمانی، همراه متن راهنمای اختیاری.
- تکلیف آزاد نوشتن و گفتن؛ پیش‌نویس قابل ذخیره و دانلود برای مدرس.
- شواهد مرور با فاصله سه روز مستقل از XP؛ نه گواهی تسلط.
- ذخیره جدید و قدیمی با کنترل نوع و محدوده خوانده می‌شود.
- تمام ۲۰ کارت گرامر و ۲۴ کارت شنیداری اکنون شناسه مستقل دارند.

به‌روزرسانی پایداری و آزمون مرورگر — ۲۰۲۶-۱۱-۱۰
- حفاظت چندتب: Web Locks برای یک نویسنده، خروجی‌گرفتن از تب مسدود، بازخوانی پیش از تحویل کنترل؛ fallback مقایسه ذخیره، اتمیک نیست.
- قفل پاسخ گرامر پس از تغییر روز آزاد می‌شود؛ ورود ذخیره و بازخوانی، وضعیت موقت و تایمرهای قدیمی را پاک می‌کنند.
- ضبط صدا: مهار درخواست تکراری/دیرهنگام مجوز، توقف track، آزادسازی URL و انتخاب فرمت پشتیبانی‌شده؛ خروج از تمرین تشخیص گفتار را متوقف می‌کند.
- تشخیص گفتار ممکن است سرویس آنلاین مرورگر باشد؛ خروجی فقط تطابق رونویسی است، نه نمره تلفظ. ضبط موقت در ذخیره پیشرفت قرار نمی‌گیرد.
- ثبت چندباره پاسخ و پاداش تکراری در بازی‌های میدان و تمرین‌های حروف/اعداد/دیکته/شنیدن مهار شد. نمایش راهنمای دیکته پاداش آن دور را حذف می‌کند؛ تایمر بازی خارج‌شده بی‌اثر می‌شود.
- آزمون‌های جدید: tabs-and-days، media، games-and-skills و Chromium واقعی. Chromium مسیر ۱۲۴ نمایش شامل هشت پرده، زبانه‌های مهارت و نماهای اصلی/میدان، Web Locks، بازخوانی آفلاین Service Worker، عرض ۳۹۰ و file:// را پوشش می‌دهد.
- تکرار کامل: Node 22.17+ در شاخه 22 یا Node 24+؛ `npm ci` و سپس `npm run test:all`. Chromium بسته‌بندی‌شده برای آزمون Linux است؛ فایل ZIP عمداً node_modules را ندارد.
- عرض موبایل در Chromium معادل گوشی واقعی نیست. میکروفون/بلندگو و ASR روی دستگاه واقعی، صفحه‌خوان، نصب PWA، بازبینی مدرس، B1 و رابط چندزبانه همچنان تأیید/پیاده نشده‌اند. CI تعریف شده؛ اجرای GitHub آن گزارش نمی‌شود. انتشار عمومی انجام نشده است.

## بازطراحی تجربه استفاده
- پوسته بصری هماهنگ‌تر با کارت‌های خوانا، رنگ‌های آرام‌تر و چیدمان موبایل.
- نوار عنوان و شرح هر بخش، جست‌وجوی فارسی/آلمانی بخش‌ها با Ctrl+K یا /، پنجره دارای برچسب و کنترل فوکوس، لینک پرش به محتوا.
- حالت تمرکز (پنهان‌کردن آمار/تب‌ها، حفظ دسترسی از جست‌وجو) و متن بزرگ‌تر؛ تنظیمات محلیِ نمایشی جدا از پیشرفت ذخیره می‌شوند.
- پشتیبانی از prefers-reduced-motion، فوکوس قابل مشاهده و حفظ پوسته در آفلاین. تست Chromium برای جست‌وجو، مسیر انتخابی، Escape، تمرکز و حفظ تنظیمات آفلاین اضافه شد.
- بازطراحی تمام محتوای آموزشی یا تضمین نبود باگ نیست؛ فونت/تصویر خارجی اضافه نشده است.
